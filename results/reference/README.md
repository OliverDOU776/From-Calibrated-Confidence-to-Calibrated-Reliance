# Reference outputs

This directory contains the compact tables used to verify the public reproduction pipeline against
the accepted manuscript.

- `tables/` contains the final offline HAIID diagnostics generated by the canonical
  `revision_diagnostics.py` analysis in the research workspace.
- `../generated/` is intentionally ignored by Git except for `.gitkeep`; reproduction commands
  write there and never overwrite these references.

The reference package does **not** contain participant-level HAIID or pilot data. See
[`data/README.md`](../../data/README.md) for source, version, checksum, license, and scope details.

Numerical verification uses explicit tolerances for floating-point columns.
