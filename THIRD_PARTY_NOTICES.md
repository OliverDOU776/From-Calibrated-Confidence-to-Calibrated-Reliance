## GRACE

The six-row table in `data/external/grace_verbalized_results.csv` transcribes published aggregate
metrics from Table 1 of:

Yoo Yeon Sung, Eve Fleisig, Yu Hou, Ishan Upadhyay, and Jordan Boyd-Graber. 2025. *GRACE: A
Granular Benchmark for Evaluating Model Calibration against Human Calibration.* Proceedings of the
63rd Annual Meeting of the Association for Computational Linguistics (Volume 1: Long Papers).
<https://doi.org/10.18653/v1/2025.acl-long.962>

No raw GRACE files are redistributed because the audited upstream repository snapshot did not
contain an explicit license file.
